## Entry is a newspaper front page, entry.png (1024x1024 PNG), that sums up 19 November 2026's world news in one image, led by the Grand Theft Auto VI launch, with the Gulf escalation, the first Trump-Putin-Xi summit, Anthropic's IPO and 37 more briefs on the page.

**main.py**

Copies the committed `entry.png` into the output directory, which is the `MAKEFUN_OUTPUT_DIR` environment variable if set, otherwise `/output`, byte for byte, standard library only, no network.

See [Bounties](https://make.fun/bounty/news-image-20261119) for more information.
